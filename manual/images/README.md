# images 目录说明

本目录存放操作手册中的界面截图。当前已自动生成 18 张真实截图（`.png`），后续如需更新：

1. 用手机浏览器（或开发者工具的手机模式）访问系统对应页面截图；
2. 建议图片宽度 375~750px，PNG 格式；
3. 将新截图覆盖对应同名 `.png` 文件即可，Markdown 无需改动。

> 也可以使用 `manual/scripts/capture-screenshots.mjs` 自动重新生成全部截图（需本地启动前后端）。
