# 换班

## 功能说明

与另一位同事交换某一天的班次：发起申请后，对方在「我收到的」里同意，系统即自动完成交换。整个换班过程受排班时间窗和排班规则约束。

![换班列表](/images/swap-list.png)

## 操作流程

### 发起换班

1. 点击右下角「发起换班」按钮。
2. **我的日期**：点击后从你的排班日历中选择要换出的日期（只显示你已排班的日期，空班次不可选）。
3. **被换班人员**：从人员列表中选择对方。
4. **被换班日期**：从对方的排班日历中选择对方的日期（同样只能选对方已排班的日期）。
5. **原因**：可填写换班原因，也可留空。
6. 点击「提交申请」。

![发起换班](/images/swap-create.png)

申请卡片会展示完整的交换信息：双方姓名、日期、班次（带颜色）、状态、原因和申请时间。

### 处理收到的申请

1. 切到「我收到的」标签。
2. 卡片中可以看到申请人、对方的班次、你的班次（交换后的结果预览）、原因和申请时间。
3. 点击「同意」立即完成交换；点击「拒绝」则申请作废。

> 同意时会做规则校验：如果交换会导致超员或某班次无人值班，会提示具体原因且交换不会生效。

### 撤回申请

- 在「我发起的」标签中，对「待处理」或「管理员审批中」的申请点击「撤回申请」，确认后申请失效。

## 状态说明

| 状态 | 含义 |
|------|------|
| 待处理 | 等待对方同意 |
| 同意 | 对方已同意（待执行/已完成，取决于流程） |
| 拒绝 | 对方拒绝 |
| 撤回 | 发起人或管理员撤回 |
| 管理员审批中 | 涉及锁定月份，需管理员审批 |
| 已完成 | 交换成功 |

## 注意事项

- 同一天只能存在一个在途的换班申请。
- 换班只能在双方都已排班的日期之间进行。
