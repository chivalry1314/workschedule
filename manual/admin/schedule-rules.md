# 排班规则与时间窗

## 功能说明

按**月份**配置排班的时间窗口和校验规则。这是管理员控制排班节奏的核心页面，包含两块配置：

1. **排班时间窗**：该月允许员工排班/换班的起止时间；
2. **排班规则**：对每人每天排班数量的三类限制。

![排班规则](/images/admin-rules.png)

## 排班时间窗

- **开始时间 / 结束时间**：在该时间段内员工可以自行排班和换班；超过结束时间系统自动锁定，不可修改。
- **未配置时间窗的月份默认不可排班**（员工只能查看）。
- 两个时间都留空表示该月一直开放。
- 时间窗只对员工生效，管理员在总排班页的调整不受限制。

## 排班规则

每个值班类型可配置三项规则（留空表示不限制，仅对所选月份生效）：

| 规则 | 配置项 | 说明 |
|------|--------|------|
| 规则1：每人每月数量上限 | 每人每月 ≤ N | 某员工该月某班次最多排 N 天 |
| 规则2：每天人数上限 | 每天人数 ≤ N | 某天的某班次最多 N 人选择，超出时后续人员无法选择 |
| 规则3：每天人数下限 | 每天人数 ≥ N | 某天的某班次至少需要 N 人；如果其他人都没选、只剩最后一人能满足，该人员必须选择该班次 |

## 操作流程

1. 用月份切换箭头选择要配置的月份。
2. 填写**开始时间**和**结束时间**，点击「保存时间窗」。
3. 在下方列表中为各值班类型填写规则数值，点击「保存规则」。

## 注意事项

- 规则保存是**整月覆盖式**的：保存时会把该月原有规则全部替换为当前填写的内容，清空某项即删除该规则。
- 规则同样约束**换班和管理员调整**：换班执行时如果会导致超员或低于下限，会被拒绝并提示原因。
- 配置规则3（下限）时，注意下限不要超过当月参与排班的总人数，否则所有人都无法保存。
