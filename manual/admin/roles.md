# 角色管理

## 功能说明

角色决定「哪些值班类型可以被该角色的人员排班」。例如：医生角色可排「A班、B班、休」，护士角色可排「A班、休」。

![角色管理](/images/admin-roles.png)

## 操作流程

### 添加角色

1. 点击「添加角色」。
2. 填写**角色名称**（如：医生、护士），备注选填。
3. 勾选该角色允许排班的**值班类型**。

![角色编辑](/images/admin-roles-form.png)

4. 点击「保存」。

### 编辑 / 删除角色

1. 点击列表中的角色进入编辑弹窗，可修改名称、备注和勾选的值班类型。
2. 点击「删除」可删除角色（已分配给人员的角色删除前请先调整人员角色）。

## 配置建议

- 建议先创建好**值班类型**（见 [值班类型管理](shift-types.md)），再回来创建角色。
- 角色划分通常对应岗位或资质，保证每个人只能排自己具备资质的班次。
