# 人员管理

## 功能说明

维护系统登录人员：添加、编辑、分配角色、重置密码、删除。只有管理员可见此页面。

![人员管理](/images/admin-users.png)

## 操作流程

### 添加人员

1. 点击左上角「添加人员」。
2. 填写**用户名**（登录用，创建后不可修改）、**姓名**、**初始密码**（至少 8 位含字母数字，员工首次登录后会被要求改密）。
3. 点击**角色**选择该人员所属角色（角色决定此人可排哪些班次）。
4. 手机号、备注为选填。
5. 点击「保存」。

![添加人员](/images/admin-users-form.png)

### 编辑人员

1. 在列表中点击该人员，进入编辑弹窗。
2. 可修改姓名、角色、手机号、备注；用户名不可修改。
3. 点击「保存」。

### 重置密码

1. 在编辑弹窗中点击「重置密码」。
2. 可直接输入新密码；**留空则系统自动生成随机密码**。
3. 点击「确认重置」，页面会显示新密码，请复制后告知员工。

### 删除人员

1. 在编辑弹窗中点击「删除」，确认后该人员无法登录，历史排班数据保留。

## 注意事项

- 首次登录的员工会被强制修改密码。
- 删除操作不可恢复，请谨慎操作。
