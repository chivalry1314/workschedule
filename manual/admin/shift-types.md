# 值班类型管理

## 功能说明

定义系统中所有的值班班次，包括名称、代码、颜色。班次在排班日历、总排班表、换班中以对应颜色展示。

![值班类型](/images/admin-shift-types.png)

## 操作流程

### 添加值班类型

1. 点击「添加值班类型」。
2. 填写**名称**（如：白班、夜班、休息）、**代码**（如：A、B、休，总排班表中优先显示代码）。
3. 选择**颜色**：可直接点击预设色板，也可以在色盘中自选任意颜色。
4. 备注选填。
5. 点击「保存」。

![值班类型编辑](/images/admin-shift-types-form.png)

### 编辑 / 删除值班类型

1. 点击列表中的类型进入编辑弹窗修改。
2. 点击「删除」可删除该类型（已被排班引用的类型请谨慎删除）。

## 注意事项

- 系统**不预置任何班次**，全部班次由管理员按团队实际情况创建。
- 建议给每个班次设置区分度高的颜色，便于在排班表中一眼识别。
